### 曾晓森 (Xiaosen Zeng)

中信证券 VP，此前在腾讯微信支付做基础架构。
做的事情基本在同一个位置上：前沿 ML 真正落到生产系统的那一层 —— 金融、电网、通信，以及底下支撑它们的分布式系统。

#### 经历

- **中信证券** — VP。大模型、Agent、面向工业系统的联邦学习
- **腾讯 · 微信支付** (2019–2024) — 基础架构。生活缴费、支付分、混沌工程
- **阿里巴巴** (实习) — 大文娱、阿里妈妈 (2016–2017)，阿里健康 (2018)

#### 当前研究方向

- **大模型** — 预训练、后训练 (SFT / RLHF / RLVR)、强化学习、深度学习
- **Agent 与 AI 产品** — Agent 架构，以及把它做成真能上线的产品
- **联邦学习** — 数据不能汇总的机构之间做隐私保护训练
- **落地领域** — 电网(故障诊断、知识图谱)、6G、量化金融

#### 技术栈
