### 曾晓森 (Xiaosen Zeng)

中信证券 VP,此前在腾讯微信支付做基础架构。
做的事情基本在同一个位置上:前沿 ML 真正落到生产系统的那一层 —— 金融、电网、通信,以及底下支撑它们的分布式系统。

- **腾讯 · 微信支付** (2019–2024) — 基础架构。生活缴费、支付分、混沌工程
